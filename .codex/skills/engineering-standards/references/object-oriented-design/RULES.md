# Object-Oriented Design

Use these guides when a task involves object responsibilities, encapsulation, inheritance, polymorphism, design patterns, or SOLID tradeoffs.

Start with the guide that matches the current decision. Do not load every reference by default.

## Contents

- [Object-Oriented Design Principles](./object-oriented-design.md): responsibility-driven design, contracts, encapsulation, value objects, entities, and aggregates.
- [SOLID Principles](./solid-principles.md): dependency direction, responsibilities, substitutability, interfaces, and extension points.
- [Design Patterns](./design-patterns.md): common creational, structural, and behavioral patterns.

## Quick Reference

| Guide | Use When | Avoid |
|------|----------|-------|
| Object-Oriented Design | Finding object boundaries and behavior ownership | Turning simple data shapes into ceremony |
| SOLID Principles | Reviewing responsibilities, dependencies, and extension points | Applying every principle mechanically |
| Design Patterns | Naming a recurring design shape that solves a real problem | Forcing patterns before the problem exists |
