# Agent Context

This folder contains shared project-specific context copied into initialized repos.

Use it for facts that make a project unique, such as folder structure, tech stack, architecture conventions, testing expectations, domain language, deployment workflows, and project-specific commands.

Keep reusable engineering standards in the `engineering-standards` skill. Keep private local notes in `AGENTS.override.md` or `CLAUDE.override.md`.

## Suggested Files

- `architecture.md`: project architecture, boundaries, and dependency direction.
- `folder-structure.md`: important directories and ownership notes.
- `testing.md`: test commands, expectations, and fixture conventions.
- `workflows.md`: build, release, deployment, and review workflows.
- `domain.md`: domain terms, business rules, and product-specific behavior.
