# prd override

Save PRDs under `docs/prd/`, named `prd-<name>.md`, where `<name>` is a short, descriptive kebab-case slug of the product or feature.

The prd skill does not specify a save location or filename by default; this override sets them. Everything else about the skill's behavior stays as-is.

Example: `docs/prd/prd-intelligent-search.md`.
