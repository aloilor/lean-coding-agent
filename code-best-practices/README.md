# Code Best Practices

This folder is the top-level index for the reusable best-practice guides in this repository.

## Guides

- [Rest API Design](./rest-api-design/README.md): guidelines for resource modeling, HTTP semantics, validation, versioning, security, and API operations.
- [Object-Oriented Programming](./object-oriented-programming/README.md): guidelines for SOLID, composition, encapsulation, and maintainable object design.
- [Clean Code](./clean-code/README.md): guidelines for naming, function design, comments, readability, and safe refactoring.
- [Design Patterns](./design-patterns/README.md): guidelines for creational, structural, and behavioral patterns, plus how to avoid misuse.
- [Observability](./observability/README.md): guidelines for logging, monitoring, alerting, tracing, and correlating production signals.
- [Git](./git/README.md): guidelines for branching, commits, rebasing, tagging, and safe history management.
- [Python](./python/README.md): guidelines for readable Python style, maintainable modules, typing, exceptions, and practical testing habits.

## Use

- Start from the guide folder that matches the problem you are working on.
- Use each folder `README.md` as the local index for the files inside it.
- Prefer the simplest rule or pattern that solves the problem in front of you.
