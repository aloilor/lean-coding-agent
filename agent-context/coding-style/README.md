# Coding Style

This folder describes how code should be written across projects that use this baseline.

Treat these guides as language-neutral defaults. When a project uses a stack with stronger conventions, follow the local project context first and use these rules as the fallback.

Start with this README and open only the topic files relevant to the current task. Treat copied reference guides as diagnostic material and review prompts, not hard lint rules.

## Contents

- [Clean Code](./clean-code/README.md): naming, functions, comments, documentation, duplication, and refactoring.
- [Code Smells](./code-smells/code-smells.md): adapted code-smells guidance from `solid-skills`.
- [Complexity](./complexity/complexity.md): copied complexity guidance from `solid-skills`.
- [Object-Oriented Design](./object-oriented-design/README.md): object design, SOLID principles, and design patterns.
