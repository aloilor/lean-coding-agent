# Lessons

- [Discuss Suggestions Before Acting](discuss-suggestions-before-acting.md) - Answer naming and design suggestions as discussion unless implementation is clearly authorized.

- [Make README Indexes Clickable](make-readme-indexes-clickable.md) - When a README serves as an index, link the referenced files so the document is directly navigable.
- [Honor Setup Installation Scope](honor-setup-installation-scope.md) - When asked to install tooling in set-up projects, make the setup script create the required project files instead of only documenting manual commands.
- [Update Setup Managed Ignore Rules](update-setup-managed-ignore-rules.md) - When ignore rules must apply to set-up repos, update the setup-managed list instead of only editing this repo's root `.gitignore`.
- [Test Initialization Structure Changes](test-initialization-structure-changes.md) - Every structural change to project initialization must include a regression test for the new structure and a rerun of the initialization checks.
