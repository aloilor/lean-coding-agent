# Workflow Guides

These pages summarize the repository's opt-in workflows. Each includes a process overview, its durable artifacts, and a diagram. The linked skill is the canonical source for the full instructions.

- [Planning only](planning.md) — clarify scope and produce an approved plan without starting implementation.
- [Feature development](feature-development.md) — plan, implement test-first, review, and verify a feature or behavior change.
- [Bug fixing](bug-fixing.md) — investigate a failure, get repair approval, fix the root cause test-first, and review.
- [Refactoring](refactor.md) — restructure code while preserving behavior, with baseline checks and independent review.
- [Code review](review.md) — review a requested scope, record findings, and report a verdict without making fixes.
