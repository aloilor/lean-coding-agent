# Use Copied Guide Folder Format For Coding Style

## Mistake Pattern

I created expanded, adapted multi-file coding-style folders when the user wanted compact copied-guide folders like `solid/`, `design-patterns/`, and `code-smells/`.

## Rule

When adding new files inside `agent-context/coding-style/`, use the copied-guide folder format unless the user explicitly asks for an adapted multi-file guide: create one topic folder containing the copied source markdown file, link it from the coding-style README, and preserve exact file content when requested.
