# Code Quality

Use these guides when a task involves complexity, refactoring risk, code smells, or maintainability diagnostics.

Start with the shortest rule that helps the current decision. Do not treat smells as automatic rewrite orders.

## Contents

- [Complexity](./complexity.md): essential vs accidental complexity, simplicity, coupling, and design pressure.
- [Code Smells](./code-smells.md): symptoms that suggest refactoring opportunities.

## Quick Reference

| Guide | Use When | Avoid |
|------|----------|-------|
| Complexity | A change feels hard to understand, risky, or over-designed | Adding indirection to look sophisticated |
| Code Smells | Reviewing or refactoring suspicious design pressure | Refactoring just because a smell name applies |
