# Place Content In The Active Target Context

## Mistake Pattern

I added new guidance to a related source/reference folder instead of the active destination the user had been building, so the content would not be copied into downstream projects as intended.

## Rule

When a request follows a thread focused on a specific destination, such as `agent-context/coding-style/`, place new content in that active target unless the user explicitly redirects to another folder. If there are parallel source and baseline trees, confirm which tree is meant before editing the wrong one.
