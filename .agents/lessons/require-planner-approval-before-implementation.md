# Require Planner Approval Before Implementation

## Mistake Pattern

Letting a planner-created specification or implementation plan flow directly into implementation skips the user's requested approval checkpoint.

## Rule

When planner output exists, show the user the specification, implementation plan, assumptions, open questions, and meaningful tradeoffs before implementation starts. Do not invoke the implementer or begin coding until the user explicitly approves the plan and specification, unless the user explicitly bypasses that gate for the current task.
